Technical Architecture & Exhaustive Codebase Guide

Production Domain: https://ecommercepro.com .NET 10 LTS SQL Server 2022

1. Executive Summary for Developers & Interviewers

This master documentation file explains every file, entity, controller, view, and design pattern in the Enterprise E-Commerce Management System. Designed for software engineers, mentors, and interviewers, it acts as a comprehensive reference guide to analyze the project in 5 minutes.

Key Features: ASP.NET Core MVC (.NET 10 LTS), EF Core 10 Eager Loading, ASP.NET Core Identity with Role Security, Session-Based Cart, Order Management & Printable Invoices, Multi-Image Upload, Chart.js Dashboard, CSV Report Export, and Automated Seed Data.

3. File-by-File Breakdown

Models Layer

  • Models/Category.cs: Category entity managing 1-to-Many product grouping.
  • Models/Product.cs: Core product entity with Price, Stock, CategoryId FK, and navigation collections.
  • Models/ProductImage.cs: Handles multi-image galleries per product.
  • Models/ApplicationUser.cs: Extends IdentityUser with FullName, Address, City, and PostalCode.
  • Models/Order.cs & OrderItem.cs: Stores order headers and line items snapshots.
  • Models/OrderStatus.cs: Enum representing Pending, Processing, Shipped, Delivered, Cancelled states.
  • Models/CartItem.cs: In-memory session object for cart management.
  • Models/Wishlist.cs: Maps user to bookmarked products.
  • Models/ProductReview.cs: Handles customer star ratings (1-5) and feedback comments.
  • Models/PaginatedList.cs: Generic LINQ pagination utility (.Skip/.Take).

Controllers Layer

  • Controllers/AccountController.cs: Registration, login, logout, and access control.
  • Controllers/CategoryController.cs: Category CRUD with FK delete validation protection.
  • Controllers/ProductController.cs: Product CRUD, dropdown binding, multi-image upload handling.
  • Controllers/HomeController.cs: Storefront catalog, search, category filter, price sorting, reviews.
  • Controllers/CartController.cs: Session cart operations (Add, Update, Remove, Clear).
  • Controllers/OrderController.cs: Checkout, stock deduction, order history, printable invoice generation.
  • Controllers/AdminController.cs: Executive dashboard stats and Chart.js datasets.
  • Controllers/ReportsController.cs: Sales reports, top-selling products, CSV export.
  • Controllers/WishlistController.cs: User wishlist management.

Data Context & Infrastructure

  • Data/ApplicationDbContext.cs: Inherits IdentityDbContext with DbSets and Fluent API configurations.
  • Program.cs: Registers services, pipeline, and seeds admin account and 8+ default products.
  • appsettings.json: Contains SQL Server connection string and domain metadata (https://ecommercepro.com).
